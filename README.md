Como estudiante de Matemáticas Aplicadas y Computación, creo firmemente que la lógica y la estructura son la base de cualquier solución tecnológica. Por eso, he diseñado este espacio con reglas muy claras sobre cómo adquiero mi conocimiento.

---

## 🧠 Mi Manifiesto de Aprendizaje (La Regla de Cero Código Generado)

En la era de la inteligencia artificial, es fácil tomar atajos. Sin embargo, mi objetivo es **construir criterio, no solo acumular código**. Para este repositorio y todos los proyectos que documente aquí, me rijo por los siguientes principios:

1. **El esfuerzo construye el conocimiento:** Ningún proyecto, script o análisis alojado aquí ha sido generado por sistemas de inteligencia artificial. 
2. **IA como Maestro Socrático:** Si utilizo herramientas de IA (como modelos de lenguaje), su único rol es actuar como tutores socráticos. Las uso para debatir ideas, entender conceptos abstractos, pedir pistas cuando estoy atascado o recibir retroalimentación sobre la eficiencia de mi código, **nunca para que escriban la solución por mí**.
3. **Aprender haciendo (y rompiendo):** Prefiero pasar horas depurando un error y entender el "por qué", que copiar una solución perfecta que no puedo explicar.

## 🗺️ Hoja de Ruta (Roadmap)

Este es el plan de estudios autodidacta que estoy siguiendo. Iré marcando los hitos conforme avance:

### Fase 1: Fundamentos Sólidos de Python 🐍
- [x] Tipos de datos, variables y operaciones matemáticas.
- [x] Estructuras de control de flujo (`if`, `for`, `while`).
- [x] Estructuras de datos (Listas, Tuplas, Diccionarios, Sets).
- [ ] Funciones, modularidad y manejo de excepciones.

### Fase 2: Manipulación y Exploración de Datos 📊
- [ ] Introducción a **NumPy**: Arreglos, operaciones matemáticas estructuradas.
- [ ] Dominio de **Pandas**: Series, DataFrames, limpieza de datos, filtrado y agregaciones.
- [ ] Importación/Exportación de datos (CSV, Excel, JSON, SQL).

### Fase 3: Visualización de Datos y Storytelling 📈
- [ ] Gráficos estáticos con **Matplotlib**.
- [ ] Visualización estadística con **Seaborn**.
- [ ] Creación de narrativas basadas en datos (Data Storytelling).

### Fase 4: Proyectos Integrales (Real-World Data) 🌍
- [ ] Análisis Exploratorio de Datos (EDA) completo.
- [ ] Integración de Python con bases de datos (SQL/PostgreSQL).
- [ ] Creación de Dashboards o reportes automatizados.
